# DialGlide Privacy Policy

Last updated: August 8, 2026

DialGlide is a Chrome extension that identifies phone numbers in phone-related webpage content and lets the user call, message, copy, or open a selected number in a configured dialer. Detection and formatting are performed locally on the user's device.

## Information handled locally

- Phone-related webpage content—including visible text and relevant links, buttons, telephone fields, labels, metadata, and structured data—is processed temporarily when the user invokes DialGlide or explicitly enables automatic detection for a website.
- Detected phone numbers and short snippets of surrounding page content for the current tab may be stored in Chrome session storage so the side panel can display the results. This session data is cleared when the browser session ends.
- Language, default country, click behavior, highlighting, calling and messaging handlers, local blocklist, custom templates, and website origins explicitly enabled by the user are stored in Chrome local storage until the user resets them or uninstalls DialGlide.
- DialGlide does not create user accounts or access names, email addresses, passwords, authentication cookies, contacts, call audio, message content, or call records.

## Information transmitted

DialGlide does not transmit webpage content, detected phone numbers, enabled website origins, browsing activity, or extension settings to the publisher. It has no publisher-operated API, analytics, telemetry, advertising, or tracking.

When the user chooses a calling, messaging, SIP, or custom dialer action, the selected phone number is handed only to the application or service chosen by the user. If the user configures a custom URL, DialGlide rejects insecure HTTP templates and permits only HTTPS URLs or supported dialer schemes. The selected application's or service's privacy terms apply.

## Permissions

- `activeTab`: temporarily access the current tab after the user invokes DialGlide.
- Optional website access: run automatically only on a website origin the user explicitly enables; access is requested one origin at a time and can be revoked independently.
- `scripting`: inject the packaged phone-number detection script and stylesheet.
- `storage`: keep local settings, explicitly enabled website origins, and current-session results.
- `contextMenus`: provide call, message, copy, and open actions for selected phone-number text.
- `sidePanel`: display detected phone numbers and user controls alongside the current page.

## Sharing, sale, and advertising

Except for user-initiated actions that open a calling, messaging, SIP, or custom dialer service, DialGlide does not sell, rent, share, or transfer user data to the publisher or third parties. It does not use user data for advertising, creditworthiness, lending, or purposes unrelated to its disclosed single purpose. No human reads user data handled by the extension.

DialGlide's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Retention and deletion

Current-tab results are retained only for the browser session. Local settings and explicitly enabled website origins remain until the user removes them, resets DialGlide, or uninstalls it. Users can also revoke any website's optional permission in DialGlide or Chrome extension settings. Uninstalling removes data stored by the extension through Chrome storage.

## Children

DialGlide is a general-purpose productivity tool and is not directed to children. It does not knowingly collect children's personal information.

## Changes

Material changes to this policy or to DialGlide's data practices will be disclosed before the updated behavior is introduced.

# سياسة خصوصية DialGlide

آخر تحديث: 8 أغسطس 2026

DialGlide إضافة لمتصفح Chrome تتعرف على أرقام الهاتف داخل محتوى صفحات الويب المرتبط بها، وتتيح للمستخدم الاتصال أو إرسال رسالة أو نسخ الرقم أو فتحه في تطبيق اتصال يضبطه المستخدم. تتم عملية الاكتشاف والتنسيق محليًا على جهاز المستخدم.

## المعلومات التي تتم معالجتها محليًا

- تتم معالجة محتوى صفحة الويب المرتبط بأرقام الهاتف مؤقتًا، بما في ذلك النص الظاهر والروابط والأزرار وحقول الهاتف والتسميات والبيانات الوصفية والبيانات المنظمة ذات الصلة، عندما يشغّل المستخدم DialGlide أو يفعّل الاكتشاف التلقائي لموقع محدد.
- قد تُحفظ أرقام الهاتف المكتشفة ومقتطفات قصيرة من محتوى الصفحة المحيط بها للتبويب الحالي في مساحة جلسة Chrome حتى تعرض اللوحة الجانبية النتائج. تُحذف بيانات الجلسة عند انتهاء جلسة المتصفح.
- تُحفظ اللغة والدولة الافتراضية وسلوك النقر والتمييز ومعالجات الاتصال والرسائل وقائمة الحظر المحلية والقوالب المخصصة وأصول المواقع التي فعّلها المستخدم صراحةً في مساحة تخزين Chrome المحلية حتى يعيد المستخدم ضبطها أو يزيل DialGlide.
- لا ينشئ DialGlide حسابات للمستخدمين ولا يصل إلى الأسماء أو عناوين البريد الإلكتروني أو كلمات المرور أو ملفات تعريف ارتباط المصادقة أو جهات الاتصال أو صوت المكالمات أو محتوى الرسائل أو سجلات المكالمات.

## المعلومات التي يتم إرسالها

لا يرسل DialGlide محتوى الصفحات أو أرقام الهاتف المكتشفة أو أصول المواقع المفعّلة أو نشاط التصفح أو إعدادات الإضافة إلى الناشر. ولا يحتوي على API تابع للناشر أو تحليلات أو قياس عن بعد أو إعلانات أو تتبع.

عندما يختار المستخدم إجراء اتصال أو رسائل أو SIP أو رابط اتصال مخصص، يُسلَّم رقم الهاتف المختار فقط إلى التطبيق أو الخدمة التي اختارها المستخدم. وترفض DialGlide قوالب HTTP غير المؤمّنة، ولا تسمح إلا بروابط HTTPS أو صيغ الاتصال المدعومة. وتُطبق شروط الخصوصية الخاصة بالتطبيق أو الخدمة المختارة.

## الصلاحيات

- `activeTab`: الوصول المؤقت إلى التبويب الحالي بعد أن يشغّل المستخدم DialGlide.
- صلاحية الموقع الاختيارية: التشغيل التلقائي فقط على أصل موقع يفعّله المستخدم صراحةً؛ وتُطلب الصلاحية لأصل واحد في كل مرة ويمكن إلغاؤها لكل موقع بصورة مستقلة.
- `scripting`: إدخال برنامج اكتشاف أرقام الهاتف وملف الأنماط المضمّنين في الحزمة.
- `storage`: حفظ الإعدادات المحلية وأصول المواقع المفعّلة صراحةً ونتائج الجلسة الحالية.
- `contextMenus`: توفير إجراءات الاتصال والرسائل والنسخ وفتح DialGlide للنص المحدد الذي يحتوي على رقم هاتف.
- `sidePanel`: عرض أرقام الهاتف المكتشفة وأدوات التحكم بجوار الصفحة الحالية.

## المشاركة والبيع والإعلانات

باستثناء الإجراءات التي يبدأها المستخدم لفتح خدمة اتصال أو رسائل أو SIP أو رابط اتصال مخصص، لا يبيع DialGlide بيانات المستخدمين أو يؤجرها أو يشاركها أو ينقلها إلى الناشر أو أطراف أخرى. ولا يستخدمها للإعلانات أو تقييم الجدارة الائتمانية أو الإقراض أو أي غرض غير مرتبط بوظيفته الوحيدة المعلنة. ولا يقرأ أي شخص البيانات التي تعالجها الإضافة.

يلتزم استخدام DialGlide للمعلومات المستلمة من واجهات Chrome البرمجية بسياسة بيانات مستخدمي Chrome Web Store، بما في ذلك متطلبات الاستخدام المحدود.

## الاحتفاظ والحذف

تُحفظ نتائج التبويب الحالي خلال جلسة المتصفح فقط. وتبقى الإعدادات المحلية وأصول المواقع المفعّلة صراحةً حتى يزيلها المستخدم أو يعيد ضبط DialGlide أو يزيل الإضافة. ويمكن للمستخدم أيضًا إلغاء الصلاحية الاختيارية لأي موقع من DialGlide أو إعدادات إضافات Chrome. وتؤدي إزالة الإضافة إلى حذف البيانات التي خزنتها من خلال مساحة تخزين Chrome.

## الأطفال

DialGlide أداة إنتاجية عامة وليست موجهة إلى الأطفال، ولا تجمع عن علم معلومات شخصية خاصة بالأطفال.
